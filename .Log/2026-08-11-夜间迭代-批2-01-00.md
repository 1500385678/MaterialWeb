   便于单测。

## P2 行 71 · Cache-Control 改造

**问题**:core.py:65 `any(s in ct for s in ('text/html', 'text/css', 'javascript'))` 字符子串
匹配 3 大风险:
1. Flask 2.x 默认 `application/javascript`(不是 text/javascript),substring 'javascript' 仍
   能命中,但换 application/ecmascript 即漏;
2. 任何含 'text/html' 子串的 Content-Type(理论 text/html_extra)被误伤;
3. ct 没 case-normalize,服务器偶发 text/HTML 大小写不一致漏匹配。

**改法**(铁律 #5「HTML/CSS/JS 全部 no-store」契约):

1. 新增模块级 `_NO_STORE_TYPES` frozenset = {text/html, text/css, application/javascript, text/javascript}
2. `ct.split(";")[0].strip().lower()` 归一化(去 charset,小写)
3. set 精确查 `_NO_STORE_TYPES`
4. 加 `Vary: Accept-Encoding` 防 gzip 缓存串
5. tests/test_cache_headers.py 覆盖 5 场景(`.html` / `.css` / `.js` / `.png` / JSON) →
   6/6 通过(`.png` 与 JSON 不强加,符合静态前端 only 策略)

**CONTROL.md 铁律 #5 同步**:描述加白名单 + 文档与代码双向对齐。
